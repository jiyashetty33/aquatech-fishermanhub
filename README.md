# AI-Powered Digital Fisheries Marketplace and Port Management System

A simple full-stack hackathon project for Mangaluru coastal operations built using Node.js, Express, MySQL, vanilla HTML/CSS/JS, JWT auth, and browser speech APIs.

## Overview

This application connects fishermen, buyers, and port officials through a digital marketplace and operational control dashboard. The system allows fishermen to manage vessels, fishing trips, catches, listings, and auctions, while officials monitor harbor operations without seeing private commercial data.

## Features

- Fisherman dashboard and vessel management
- Port official operational dashboard
- Buyer marketplace with auctions and direct sales
- AI voice assistant with confirmation and TTS
- JWT auth and authorization separation
- Private commercial data protection for official users
- Multilingual UI in English, Kannada, Tulu, Malayalam
- Demo payment flow and notifications
- MySQL schema with seed data

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: MySQL
- Auth: JWT + bcryptjs
- AI integration: backend-only structured intent parsing
- Voice: browser SpeechRecognition and SpeechSynthesis

## Setup

1. Install dependencies:
   npm install
2. Create MySQL database and tables using schema.sql and seed.sql.
3. Copy .env.example to .env and fill in your values.
4. Run:
   npm start
